# Custom team cutouts (optional)

Drop a transparent-background PNG here to use it as a team's hero image in
graphics (matchup posters, stat cards, record cards). This is the way to get
hand-made action cutouts — the kind you can't source automatically.

**Naming:** name the file after the team's ESPN abbreviation, e.g.
`ADL.png` for "The Island boys", `CCC.png` for "FLACCID WINNERS". (Abbrevs come
from the ESPN export; ask the bot/logs if unsure.) `.png`, `.jpg`, and `.webp`
are supported. PNGs with transparent backgrounds look best.

**Priority:** a cutout here overrides the automatic player headshot. If no
cutout is present, the graphic uses the team's marquee player's real ESPN
headshot, and if that's unavailable, the team logo / monogram crest.

You do **not** need to add team logos here — those are pulled from ESPN
automatically.
